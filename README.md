# OREO 2027 · Explorador de recorridos

Explorador interactivo del árbol de decisiones en español e inglés. HTML, CSS y JavaScript sin dependencias ni proceso de compilación.

## Incluye

- Flujo de 147 pasos y 181 conexiones por idioma.
- Min mapa de páginas estilo metro, navegación por estaciones y tooltips.
- Separación entre páginas y módulos, acciones físicas y digitales.
- Cabecera sticky, reinicio del recorrido y diseño adaptable desde 360 px.
- Historial local, enlaces al recorrido y exportación a texto.
- Soporte de teclado y movimiento reducido.

## Ejecutar

Sirve esta carpeta mediante un servidor HTTP, por ejemplo `python -m http.server 8000`, y abre http://localhost:8000.

## GitHub Pages

En Settings → Pages, selecciona Deploy from a branch, la rama main y la carpeta raíz.

El flujo es una instantánea, no una sincronización en directo con FigJam. No realiza registros, canjes ni operaciones reales. Las rutas y la sintaxis se han comprobado; la revisión visual en navegador está pendiente.
